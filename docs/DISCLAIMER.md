# Disclaimer (library note)

bio-core is a mechanism library, not a user-facing product. It ships the
single-source disclaimer *model* (evidence tiers, "research association not
diagnosis" framing) used by the downstream products, but the user-facing
disclaimer text is owned and presented by each product (MethylAsk, GeneAsk).

Findings produced through bio-core carry an evidence tier describing how much
scientific support exists for an association — never a statement about an
individual's health.
